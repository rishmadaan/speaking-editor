# Contributing

Contributions are accepted under the terms in LICENSE-NOTICE.md: AGPLv3 only
with the Obsidian additional permission in LICENSE-EXCEPTION.md. Submit only
work you have the right to contribute under those terms, and retain notices for
any third-party material. You retain your copyright; no assignment is required.

First-party engine changes use these same terms. Reusing later contributions
under a different license requires appropriate permission from their owners.

Start with a numbered spec in specs/. Follow AGENTS.md for the engine/shell
boundary, test-first workflow, and verification gates. Changes to AGENTS.md must
also be made in CLAUDE.md. See COMMIT_CHECKLIST.md before committing.
